# Neuro-Exo
This is the dedicated GitHub of the University of Houston's New NeuroExo Senior Design project that focuses on giving stroke patients 
with arm impairment their mobility back through a current-controlled dynamically assistive/resistive device. 


The current BeagleBone → Nano → Teensy motor interface uses separate BLE command
and telemetry characteristics. See the [setup guide](H_Robotics_Files/BEAGLEBONE_READER_PROCEDURE.md)
and [binary protocol](H_Robotics_Files/NEUROEXO_PROTOCOL.md). The old BLE benchmark
and simulated trial tools have been removed.
